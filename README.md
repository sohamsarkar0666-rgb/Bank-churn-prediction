# 🏦 Bank Customer Churn Prediction — Machine Learning

A machine learning classification project that predicts whether a bank customer will churn (leave the bank) based on their demographic and account information.

## 🚀 Features
- End-to-end ML pipeline from data cleaning to model evaluation
- Handles class imbalance for better prediction on minority class
- Compares multiple classification algorithms
- Hyperparameter tuning for optimal performance
- Feature importance analysis for business insights

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn
- **Models:** Logistic Regression, Random Forest, Gradient Boosting, AdaBoost
- **Platform:** Jupyter Notebook / Kaggle

## 💡 How It Works
1. Load and explore the dataset (EDA)
2. Handle missing values and encode categorical features
3. Handle class imbalance
4. Train multiple ML models
5. Evaluate using Accuracy, F1-Score, Precision, Recall
6. Select best model based on performance
